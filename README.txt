الملفات الأساسية للموقع:
- HTML صفحات مستقلة.
- assets/style.css تصميم responsive واتجاه RTL.
- assets/app.js قائمة الدروس ومحتواها والتصفية.
- assets/logo.svg شعار مؤقت مخصص للموقع.

المحتوى التعليمي النصي موجود داخل assets/app.js. أما فيديوهات الدروس فهي غير مضافة، لأن إدخال روابط فيديو حقيقية يحتاج روابطك الخاصة. مساحة الفيديو مجهزة في صفحة الدرس.
