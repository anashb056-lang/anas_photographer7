# موقع أنس فوتوغرافي — أكاديمية التصوير

هذا موقع static متكامل كبداية نشر: صفحات مستقلة، تصميم عربي RTL responsive، مكتبة دروس قابلة للبحث والتصفية، صفحات درس منفصلة، صفحة تعريف، ونموذج تواصل يفتح WhatsApp.

## الصفحات
- `index.html` الرئيسية
- `courses.html` قائمة الدروس مع البحث والفلاتر
- `lesson.html?id=exposure` صفحة درس ديناميكية بحسب المعرّف
- `about.html` عن الأكاديمية
- `contact.html` التواصل

## تنبيه مهم بخصوص الفيديوهات
المحتوى النصي الأساسي مكتوب وموجود داخل `assets/app.js`. لا توجد روابط فيديو مصطنعة. منطقة الفيديو موجودة في كل درس وتنتظر روابط YouTube الفعلية التي تملكها. لإضافة فيديو، أرسل روابط الفيديوهات أو ضع روابط embed داخل بيانات الدروس.

## نشر مجاني عبر GitHub Pages
1. فك ضغط الملف.
2. سجّل دخولك إلى GitHub وأنشئ repository جديدًا، مثل `anas-photography`.
3. ارفع **كل الملفات الموجودة داخل المجلد** إلى جذر المستودع (لا ترفع ملف ZIP نفسه).
4. افتح Settings → Pages.
5. في Build and deployment اختر `Deploy from a branch`، ثم `main` و`/(root)`، واضغط Save.
6. انتظر انتهاء النشر؛ سيظهر رابط الموقع في صفحة Pages. قد يستغرق الإعداد الأول بضع دقائق.

## نشر عبر Netlify (طريقة بديلة)
1. فك ضغط ZIP.
2. افتح Netlify وأنشئ حسابًا.
3. اسحب المجلد الذي يحتوي `index.html` وملفات assets إلى مساحة النشر اليدوي في Netlify.
4. سيعطيك Netlify رابطًا عامًا للموقع.

## تخصيص
- اسم وهوية الموقع: صفحات HTML و`assets/logo.svg`.
- الألوان والتنسيق: `assets/style.css`.
- الدروس النصية: `assets/app.js` في مصفوفة `lessons`.
- حساب Instagram: الروابط الحالية تستخدم `anas_photographer7`.
- التواصل: النموذج يفتح WhatsApp دون تخزين معلومات المستخدم.

## ما لا يتضمنه هذا الإصدار
هذا الموقع static؛ لا يوجد تسجيل دخول، لوحة إدارة، حفظ تقدم، أو رفع فيديوهات/دروس من داخل الموقع. هذه تحتاج backend أو خدمة منفصلة. النشر هو الذي يجعل الموقع متاحًا على الإنترنت، ولا أستطيع نشره داخل حسابك دون وصولك وتنفيذك خطوات الاستضافة.
